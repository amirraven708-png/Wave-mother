
## ⚠️ Status: Reference Implementation

The cryptographic primitives (Kyber-1024, AEAD) in `raven-vpn/` are currently
**placeholders** for development and testing. Production integration with
`liboqs` / `pqcrypto` is planned. Do **not** use this code for real traffic
until the quantum-safe handshake is fully implemented and independently audited.
